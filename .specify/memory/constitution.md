# Jev Skills Constitution

Version 1.0.0. Adopted 2026-09-22.

1. Jev selects from supplied candidates. The coding agent owns reasoning, permissions, execution, and mandatory verification. A model score is never authorization.
2. Network is opt-in. Automatic workflows start off; private inputs and contextual follow-ups bypass Jev. The package installs no interception hooks.
3. Fail open to the host. Use bounded deadlines and conservative validation. Do not claim zero overhead, guaranteed correctness, or measured savings without evidence.
4. Keep the package portable. Python 3.10+, a shared CLI, standard SKILL.md manifests, host-aware installation, and no personal paths or assumed model inventory.
5. Verify before publishing. Offline tests must cover safety boundaries. Live results must retain failures and separate synthetic measurements from production claims.
6. New behavior starts in specs with a plan and tasks. Keep STATUS.md current. Never publish secrets, private catalogs, or !notes directories.

This repository was initialized with GitHub Spec Kit 1.0.5. Generated local agent templates are intentionally not part of the distribution.
