# Launch draft

This is a draft, not a record of a published post. Claims deliberately exclude guaranteed speed, accuracy, or savings.

## Main X post

```text
I made Jev Skills: 7 small decision helpers for Claude Code and Codex.

Pick a model, find a skill, choose what to inspect or test next. Jev suggests; your agent does the work.

Off by default. Code, examples and live test results:
https://github.com/n23eos/jev-skills
```

## Optional follow-up

```text
The useful limit: Jev only chooses from candidates you provide. It doesn't run a skill or switch the model in your current chat.

Low confidence or a timeout? The agent carries on normally. I'd like to see requests where the picker gets it wrong.
```

## A small launch plan

1. Publish the main post with the repository link and one short recorded CLI example. Show a real result, including its latency and fallback state if any.
2. In a reply, link the evaluation report and explain that it uses synthetic labels, not production benchmarks. Invite a failing input and expected answer as a reproducible issue; remind contributors to remove private data.
3. Share once in relevant coding-agent or TypeSafe communities where self-promotion is allowed. Answer concrete questions, fix reproducible problems, and post a follow-up only when there is a meaningful result.

Do not mass-tag users, automate unsolicited replies, buy engagement, or present simulated adoption as real usage.
